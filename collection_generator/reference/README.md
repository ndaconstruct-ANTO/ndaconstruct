# Image maître officielle 🦁

Placez ici **votre illustration officielle** du lionceau maître, nommée :

```
master_lion.png
```

Cette image est la **référence visuelle immuable** de toute la collection.
Quand `master_model.use_reference_image: true` (dans `config/collection.yaml`)
et que ce fichier existe, la **génération réelle** part de cette image
(édition basée référence) pour conserver **exactement le même lionceau** :
même tête, même visage, même morphologie, même posture — seuls changent le
pelage, les yeux, la tenue, les chaussures, le couvre-chef et l'objet tenu.

> Le fichier `master_lion.png` fourni par défaut est un exemple généré.
> **Remplacez-le par votre modèle officiel** pour verrouiller votre identité.

Recommandations pour l'image maître :
- format carré 1:1, fond blanc pur ;
- lionceau debout, de face, entièrement visible (tête → chaussures) ;
- pose neutre, bras le long du corps ;
- rendu 3D ultra-réaliste.
